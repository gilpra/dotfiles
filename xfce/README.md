# XFCE Dotfiles

> Clean & minimal XFCE setup with Arch Linux.

## Stack

- **OS:** Arch Linux
- **WM:** Xfce
- **Theme:** Gruvbox
- **Terminal:** Alacritty
- **Shell:** Fish

## Installation

Clone this repo to `$HOME`:

```bash
git clone https://github.com/gilpra/dots-xfce ~/.dotfiles/dots-xfce

cd ~/.dotfiles/dots-xfce
```

Run automatic setup:

```bash
./setup.sh
```
