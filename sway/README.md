# Sway Dotfiles

> Clean & minimal Sway setup with Arch Linux.

## Stack

- **Operating System:** Arch Linux
- **Window Manager:** Sway
- **Theme:** Tokyo Night
- **Terminal:** Foot
- **Shell:** Zsh

## Installation

Clone this repo to `$HOME`:

```bash
git clone https://github.com/gilpra/dots-sway ~/.dotfiles/dots-sway

cd ~/.dotfiles/dots-sway
```

Run automatic setup:

```bash
./setup.sh
```
